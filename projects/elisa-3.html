Project 02 / Embedded control

Elisa-3 Robot Control

Programming an Elisa-3 robot to respond to its surroundings: following a line, avoiding obstacles and testing behaviours on a physical course.

Role

Team leader · Three-person team

Period

March–May 2025

Tools

Arduino · PID control

Platform

Elisa-3 / ATmega2560

01 / The task02 / My contribution03 / Demonstration04 / Reflection

01 / The task

Make sensing turn into behaviour.

The embedded systems project covered object following, obstacle avoidance within a bounded area, and combined line and corridor following. Our three-person team worked with the Elisa-3 mobile robot.

My direct programming work focused on line following and obstacle avoidance using Arduino, with PID control for line-following motion.

02 / My contribution

Code, coordinate and test.

Embedded programming

PID line following.

I programmed the robot’s line-following behaviour, applying PID control to adjust its motion in response to the line.

Robot behaviour

Obstacle avoidance.

I worked on obstacle-avoidance behaviour and tested the robot’s response on the physical setup.

Team coordination

A shared development plan.

I organised milestones and task allocation, coordinating work on sensor processing, robot behaviours and code review.

Integration

Check it on the robot.

I supported implementation and testing across the team’s behaviour tasks, checking how the developed code worked on real hardware.

03 / Demonstration

From the test bench.

9-second team demonstration with a movable box. This clip illustrates the robot setup and behaviour testing; it is not a quantitative benchmark of PID tracking performance.

04 / Reflection

The system matters as much as the code.

This project connected embedded programming with practical robot testing. It also gave me experience dividing a robotics task across a team and bringing the work together on one platform.

For a future iteration, I would log tracking error and obstacle-response timing to make controller changes easier to evaluate quantitatively.

Team outcomes are distinguished from my individual contribution above. No tracking-accuracy or success-rate claims are made without a recorded benchmark.
