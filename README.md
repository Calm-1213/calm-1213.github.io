# Yuzhou Li — Robotics Portfolio

Personal engineering website for CPD coursework and robotics applications.

The public website source is maintained in this repository. The CV has an HTML page at `cv.html` and a PDF download at `assets/Yuzhou-Li-CV.pdf`.

## Editing

Edit `index.html`, `styles.css`, `cv.html`, and the case studies in `projects/`. Files in `assets/` are native website images, videos, and documents.

## Coursework release

Keep the submitted website online for at least three weeks after submission. Do not modify it after the submission deadline. Check the exact Canvas deadline before final release.
